# Project Butler

一个供编码 Agent 使用的个人 AI 资产管家技能：用一个本地主目录保存共享规则、项目进度和知识，供多个具备文件访问权限的 Agent 接入。

功能完成或重要阶段结束时记录实现位置、使用方法、验证结果和下一步，帮助后续会话恢复；记录仍需结合实际代码和环境核对。

## 安装或接入

将 [`SKILL.md`](SKILL.md) 保存到当前 Agent 支持的 `project-butler` 技能目录，或让 Agent 读取该文件。首次选择主目录，已有资产库直接复用；按技能中的初始化步骤保存共享规则源、配置当前 Agent 的入口。

其他 Agent 首次接入时，可以告诉它：

> 读取 `<主目录>`，接入项目管家，检查安装并使用现有项目进度和知识库。

管家也会在当前项目的交接文档中加入主目录、共享技能和资产索引入口。新 Agent 接手时读取该文档，就可以发现入口并按自身支持的方式检查或配置接入；只有实际读取文档且具备相应权限时才可能生效。

不同 Agent 的安装目录、自动加载能力和文件权限不同，可能需要额外配置或开启新会话。技能不会自行把资产上传到 GitHub，也不保证中断或压缩时绝不遗漏。

网站与安装说明：[butler.aijunjz.com](https://butler.aijunjz.com/)。

## 安全

不要将密码、令牌、Cookie 或环境变量中的密钥值写入知识库。同步任何个人资产前，请先检查内容及仓库访问范围。
